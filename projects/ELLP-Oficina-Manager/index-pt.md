Sistema web desenvolvido para o Projeto ELLP (Espaço de Leitura, Letramento e Programação) da UTFPR, com o objetivo de centralizar e informatizar o gerenciamento das oficinas oferecidas pela instituição.

A aplicação foi criada a partir de uma demanda real, substituindo processos manuais de cadastro de participantes, controle de frequência e emissão de certificados por uma plataforma integrada.

O sistema contempla gerenciamento de alunos, voluntários, oficinas, encontros, matrículas, frequência e certificados, utilizando autenticação segura e controle de acesso baseado em papéis (RBAC).

O projeto envolve levantamento de requisitos, modelagem de banco de dados relacional, definição de arquitetura backend/frontend e implementação de uma solução escalável utilizando boas práticas de engenharia de software.
