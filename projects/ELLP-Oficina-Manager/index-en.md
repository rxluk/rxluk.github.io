Web system developed for the ELLP Project (Reading, Literacy and Programming Space) at UTFPR, aiming to centralize and digitalize the management of educational workshops offered by the institution.

The application was created based on a real institutional demand, replacing manual processes for participant registration, attendance tracking, and certificate generation with an integrated platform.

The system includes management of students, volunteers, workshops, meetings, attendance records, and certificates, using secure authentication and role-based access control (RBAC).

The project involves requirements engineering, relational database modeling, backend/frontend architecture design, and implementation of a scalable solution following software engineering best practices.
