title: Sistema de Gestão para Restaurantes
stack: Java 21, Spring Boot, React, PostgreSQL, WebSockets, Docker, JWT, Hexagonal Architecture
---
Sistema completo desenvolvido para um cliente real, com foco no gerenciamento de pedidos, mesas e operações de vendas em bares e restaurantes.

A aplicação foi projetada para otimizar o fluxo operacional do estabelecimento, permitindo acompanhamento de pedidos em tempo real através de WebSockets, controle de estoque com atualização automática conforme movimentações, relatórios de vendas e gerenciamento de usuários com autenticação segura e controle de acesso baseado em papéis.

O projeto utiliza uma arquitetura organizada baseada em **Arquitetura Hexagonal**, separando regras de negócio, infraestrutura e interfaces para facilitar manutenção e evolução do sistema.
