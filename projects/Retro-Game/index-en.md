Retro gaming console developed using a Raspberry Pi Zero 2W as the main platform, integrating a display, physical buttons, and electronic components through a breadboard and jumper wires.

The project involved assembling the circuit using Raspberry Pi GPIO pins, configuring RetroPie, mapping physical controls, and adjusting software settings for component recognition and proper display output.

Beyond programming, the development required knowledge of electronics, pin mapping, hardware-software communication, embedded systems configuration, and real-world component integration.
