Console portátil de jogos retrô desenvolvido utilizando uma Raspberry Pi Zero 2W como plataforma principal, integrando display, botões físicos e componentes eletrônicos através de protoboard e jumpers.

O projeto envolveu a montagem do circuito utilizando os GPIOs da Raspberry Pi, configuração do RetroPie, mapeamento dos controles físicos e ajustes de software para reconhecimento dos componentes e correta exibição da interface no display.

Além da programação, o desenvolvimento exigiu conhecimentos de eletrônica, pinagem, comunicação entre hardware e software, configuração de sistemas embarcados e integração de componentes reais.
