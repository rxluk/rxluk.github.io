Assistente robótico de mesa desenvolvido como projeto pessoal, combinando Inteligência Artificial, programação embarcada e hardware acessível.

O Mander utiliza Raspberry Pi Zero 2W como plataforma principal, integrando processamento de linguagem natural, modelos de linguagem locais via Ollama e uma arquitetura híbrida utilizando Python para lógica de alto nível e C para componentes de baixo nível.

O projeto explora a criação de uma interface física para interação com IA, conectando software ao mundo real através de áudio, sensores e futuras integrações como visão computacional e automação inteligente.
