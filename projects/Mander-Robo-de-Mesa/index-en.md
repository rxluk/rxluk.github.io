Desktop robotic assistant developed as a personal project, combining Artificial Intelligence, embedded programming, and accessible hardware.

Mander runs on a Raspberry Pi Zero 2W, integrating natural language processing, local language models through Ollama, and a hybrid architecture using Python for high-level logic and C for low-level components.

The project explores creating a physical interface for AI interaction, connecting software with the real world through audio, sensors, and future integrations such as computer vision and intelligent automation.
